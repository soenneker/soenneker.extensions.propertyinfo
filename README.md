# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Extensions.PropertyInfo
Extension methods for inspecting and transforming reflection `PropertyInfo` metadata.

## Installation

```bash
dotnet add package Soenneker.Extensions.PropertyInfo
```

## Current API

This package does not currently expose any extension methods. It contains only the empty `PropertyInfoExtension` type, so installing it will not add behavior to `PropertyInfo` values yet.
