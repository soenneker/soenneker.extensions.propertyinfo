# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Extensions.PropertyInfo
An empty extension namespace reserved for reflection `PropertyInfo` APIs.

## Installation

```bash
dotnet add package Soenneker.Extensions.PropertyInfo
```

## API surface

This package contains the empty static type `PropertyInfoExtension`. It defines no extension methods, dependencies, configuration, or runtime behavior. Installing it does not add operations to `PropertyInfo` values.
